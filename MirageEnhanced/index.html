About this page

This is a companion reference hub, not a modified game client — the game itself opens directly on its own site, in its own tab, so login and account features work exactly as the developers built them. The lookup tools pull from community-maintained reference pages.

Mirage Companion is an independent, fan-made reference tool and is not affiliated with, endorsed by, or operated by the developers of Mirage Online Classic. All game content, trademarks, and the game client itself belong to their respective owners.
